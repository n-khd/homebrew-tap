# Tap Homebrew de Najmabdi7

```sh
brew install --cask najmabdi7/tap/macclair
```

| Cask | Application |
|---|---|
| `macclair` | [MacClair](https://github.com/Najmabdi7/MacClair) — utilitaire macOS libre d’analyse du stockage |

Le cask est mis à jour automatiquement par le workflow `.github/workflows/bump.yml`, qui lit la
dernière release de MacClair et reporte sa version et sa somme SHA-256.
